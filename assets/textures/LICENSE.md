# Block textures

The files in `source/` are 16×16 block textures from the OpenGameArt set
"16x16 block texture set": https://opengameart.org/content/16x16-block-texture-set

- License: **CC0 1.0** (public domain), as listed on the page.
- The page names ARoachIFoundOnMyPillow as the uploader. Check the page if the
  author credit matters for you.

Each file is used unchanged. `src/assets/blocks-atlas.png` is built from them
by `tools/build-atlas.py`. The water and bedrock tiles are generated by that
script, not taken from the set.
